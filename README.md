# Проверка учебных работ — релиз 1.0

Учебное web-приложение: студент выбирает курс, отправляет файл работы и получает оценку, комментарий и рекомендации. Преподаватель управляет своими курсами и заданиями, скачивает работы и проверяет их. Администратор назначает роли, блокирует пользователей и просматривает журнал действий.

## Запуск

Нужны Node.js 24 и PostgreSQL 16. Docker необязателен: можно использовать установленный PostgreSQL. Создайте две отдельные базы `review` и `review_test` и укажите подключения в `.env` по образцу `.env.example`.

```powershell
npm ci
npm run db:generate
npm run db:migrate
npm run db:seed
npm run build
npm start
```

Откройте http://127.0.0.1:3000. `db:seed` создаёт учебные аккаунты `student@study.local`, `teacher@study.local`, `admin@study.local` с паролем `Study2026!`. Регистрация создаёт только студента; другую роль назначает администратор. Начальное заполнение предназначено для локальной демонстрации. Для реального размещения нужны HTTPS, собственные аккаунты и резервное копирование базы и каталога файлов.

Файлы хранятся в `data/files` (переопределяется `FILE_STORAGE_DIR`), метаданные и остальные данные — в PostgreSQL. Допускаются PDF, DOCX, TXT и ZIP до 5 МБ. Данные сохраняются после перезапуска. Остановка сервера: Ctrl+C.

## Проверки

```powershell
npx playwright install chromium
npm run quality
```

Полный набор: форматирование, ESLint, TypeScript, 142 проверки Vitest, сборка и 31 сценарий Chromium. Из них 98 модульных, 44 интеграционных, 25 проверок прежнего автономного прототипа и 6 сценариев полной версии. Интеграционные проверки используют отдельную базу с именем, оканчивающимся на `_test`, и очищают её. `TEST_DATABASE_URL` должен указывать именно на неё. Браузерный сервер запускается автоматически на 127.0.0.1:3188.

Результаты: `reports/summary.html`, `reports/metrics.json`, `reports/task-results.json`; подробности — `npm run test:report`. Покрытие относится к серверному TypeScript и хранилищу старого прототипа; React-интерфейс проверяется сценариями, его процент покрытия не измеряется. Состояние обязательной проверки `quality` в GitHub Actions проверяется перед слиянием в main.

## Структура

| Путь               | Назначение                                   |
| ------------------ | -------------------------------------------- |
| src/release        | Полное API, пароли, сессии, начальные данные |
| src/reviews        | Правила проверки учебных работ               |
| src/infrastructure | Репозиторий Prisma и транзакции              |
| web/src            | Интерфейс React                              |
| prisma             | Схема и миграции PostgreSQL                  |
| tests              | Модульные, интеграционные и браузерные тесты |
| scripts            | Сборка, проверки и метрики                   |
| prototype          | Предыдущий автономный прототип для регрессии |

Старый HTTP-модуль с демонстрационными токенами сохранён для регрессионных тестов. Точка запуска релиза подключает только API с сессиями. Курс связан с преподавателем, задание — с курсом, работа — с заданием и студентом. Решение, уведомление и событие журнала записываются транзакционно. Чужие работы и файлы недоступны; блокировка или смена роли завершает существующие сессии.

## Границы учебной версии

Курсы доступны всем зарегистрированным пользователям. Одна работа на задание; повторная отправка после отклонения не предусмотрена. Нет почтовой рассылки, восстановления пароля и антивирусного сканирования: уведомления внутренние. Поиск небольшого учебного каталога выполняется с нормализацией регистра русского языка в приложении. Публикация в интернете требует отдельной настройки инфраструктуры.
