# Прототип: лабораторная работа №6

Цель — проверить понятность основного сценария: список заданий → отправка → очередь преподавателя → рецензия → результат и уведомление.

Из исходного плана выбраны задачи №10, 11, 13, 14, 15, 16 и 18. Полноценная реализация этих задач в серверном приложении не объявляется завершённой.

## Запуск без установки

Откройте готовый `prototype.html` в Chrome, Edge или Firefox. Он содержит React, программу и оформление внутри одного файла. Интернет, Node.js, Docker, PostgreSQL и расширения редактора для показа не нужны.

Исходники находятся в `prototype/src`. Для пересборки разработчику нужны Node.js 24 и установленные зависимости:

```text
npm ci
npm run build:prototype
```

Результат: `prototype/dist/prototype.html`. Команда `npm run build` собирает сервер и HTML-прототип; CI сохраняет оба результата.

## Сценарий показа

1. В режиме студента откройте первое задание «Описание требований к системе».
2. Выберите любой небольшой PDF, DOCX, TXT или ZIP до 5 МБ, добавьте комментарий и отправьте работу.
3. Переключите режим на преподавателя. Откройте отправленную работу из очереди.
4. Введите оценку 85, комментарий и рекомендации. Сохраните рецензию.
5. Переключитесь на студента. Откройте уведомление и результат проверки.
6. Для альтернативного сценария отклоните вторую учебную работу с указанием причины.
7. Кнопка «Начать демонстрацию заново» возвращает исходные примеры.

## Границы прототипа

- Это интерактивный интерфейс с локальными учебными данными; сервер API и PostgreSQL в данном режиме не подключены.
- Переключение роли служит для демонстрации. Оно не заменяет авторизацию. Реальная защита должна выполняться сервером.
- Для выбранного файла сохраняются только имя и размер. Содержимое не отправляется и не доступно для скачивания.
- Результаты хранятся в localStorage данного браузера, если это разрешено. При блокировке хранилища возможна работа только в текущем сеансе. Между компьютерами данные не синхронизируются.
- Правила оценки и отклонения переиспользуются из `src/reviews/service.ts` лабораторной №5. Вместо Prisma подключено браузерное хранилище с тем же интерфейсом `IReviewRepo`.
- Основной сценарий проверяется на учебных пользователях; интерфейс администратора, регистрация, CRUD курсов и реальное файловое хранилище отсутствуют.

Необходимо согласовать с преподавателем шкалу 0–100, допустимые форматы и размер файлов, обязательность рекомендаций и порядок повторной сдачи после отклонения. Предварительные решения прототипа не являются согласованными требованиями.
