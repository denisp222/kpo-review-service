# Проверка релиза 1.0

Полный запуск описан в README. Команда `npm run quality` формирует сводку и завершается ошибкой при провале любого обязательного этапа. Порог покрытия — 80% строк, ветвей, функций и инструкций. Повторные попытки браузерных сценариев отключены.

Все 21 исходные задачи связаны с браузерными сценариями через метки T1–T21. Один сквозной сценарий проверяет несколько задач. Отрицательные случаи, доступ к чужим данным, ограничения загрузки, срок сдачи, повторная проверка, сессии и блокировки дополнительно проверяются через HTTP с настоящей PostgreSQL. Это проверка заявленного учебного объёма, а не гарантия отсутствия любых дефектов.

Базы демонстрации и тестов разделены. Пользовательские проверки полной версии обращаются к локальному HTTP-серверу, старого прототипа — к автономному HTML без сети. Мобильный сценарий проверяет ширину 390 пикселей.
