# Замеры по этапам

Первый фактический замер модуля выполнен 27.10.2026 и обозначен `lab5-baseline`. За более ранние этапы исходного кода и измерений нет.

| Поле                                   | Что измеряется                                    |
| -------------------------------------- | ------------------------------------------------- |
| lintErrors, lintWarnings               | Число ошибок и предупреждений ESLint              |
| testsPassed, testsFailed, testsSkipped | Результаты отдельных тестов Vitest                |
| testSeconds                            | Время команды тестирования, включая сбор покрытия |
| lineCoveragePercent                    | Выполненные строки / учитываемые строки × 100%    |
| branchCoveragePercent                  | Выполненные ветви / учитываемые ветви × 100%      |
| buildSeconds                           | Время компиляции TypeScript                       |
| qualitySeconds                         | Время всего набора проверок и сборки              |

Время указано в секундах. `null` означает отсутствие данных, а не нулевое значение. Замеры времени на разных компьютерах напрямую не сравниваются.

В конце каждого следующего этапа сохраняется отдельный JSON командой `npm run snapshot -- --stage <этап>`. Его дата и SHA позволяют повторить проверку нужной версии. Имена этапов и порядок работы приведены в основном README.
